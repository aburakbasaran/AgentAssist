## Known Production Gaps (out of scope this sprint)

- Production auth (Entra ID + JWT bearer + policy authorization).
- APIM (rate limiting, WAF, JWT validation, IP allowlist).
- Private Endpoint / VNet integration (App Service, Azure SQL, Search, OpenAI, Key Vault).
- Production-mode anonymous fail-fast guard.
- Automated knowledge ingestion pipeline (manual `az search` push commands documented).
- "Audit-or-fail" policy (current policy is best-effort with warning log).

These gaps are documented in ADR-0010 and `docs/azure/production-pilot-azure-setup.md` "Optional production hardening".
